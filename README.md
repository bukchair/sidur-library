# The library of the Karlin-Stolin siddur

Hebrew texts for the free siddur app (https://bukchair.github.io/sidur/), prepared from Sefaria's public export.
Every book keeps its edition and licence in catalog.json (`version.title`, `version.license`, `version.source`), and
the app shows them under every page. Texts under a non-commercial licence are used because the app is free.
